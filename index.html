Что такое HTML?

HTML (HyperText Markup Language — «язык гипертекстовой разметки») — это язык, на котором создаются все сайты в интернете. Он не является языком программирования: в нём нет вычислений и условий. HTML просто говорит браузеру, что где находится на странице: вот заголовок, вот абзац, вот картинка, а вот ссылка.

Чтобы начать, понадобится совсем немного:

  • компьютер (подойдёт и ноутбук школьный);
  • любой браузер — Chrome, Firefox, Edge или Safari;
  • текстовый редактор — например, Блокнот или бесплатный Visual Studio Code;
  • немного терпения и любопытства 🙂
💡 Совет: HTML — самый простой первый шаг в мир создания сайтов. Уже через час вы сможете сделать свою первую страницу!

Твоя первая страница

Любая HTML-страница имеет одинаковый «скелет». Скопируй этот код в Блокнот:

<!DOCTYPE html>
<html lang="ru">
<head>
  <meta charset="UTF-8">
  <title>Моя первая страница</title>
</head>
<body>
  <h1>Привет, мир!</h1>
  <p>Это моя первая веб-страница.</p>
</body>
</html>

Как запустить?

  1. Сохрани файл с именем index.html (тип файла — «Все файлы», кодировка UTF-8).
  2. Дважды щёлкни по файлу — он откроется в браузере.
  3. Меняй текст в Блокноте, сохраняй и обновляй страницу клавишей F5.

Из чего состоит скелет?

Основные теги

Тег — это команда в угловых скобках. Большинство тегов бывают парными: есть открывающий <p> и закрывающий </p> (со слэшем). Между ними находится содержимое.

Ссылки и картинки

Ссылка состоит из адреса (href) и текста, на который нужно нажать:

<a href="https://ru.wikipedia.org" target="_blank">Открыть Википедию</a>

Списки

Списки помогают упорядочить информацию. Бывают два вида:

Маркированный список (<ul>)

<ul>
  <li>Яблоко</li>
  <li>Груша</li>
  <li>Банан</li>
</ul>

Результат:

  • Яблоко
  • Груша
  • Банан

Нумерованный список (<ol>)

<ol>
  <li>Открыть Блокнот</li>
  <li>Написать код</li>
  <li>Сохранить файл</li>
</ol>

Результат:

  1. Открыть Блокнот
  2. Написать код
  3. Сохранить файл

Как сделать таблицу

Таблица строится из строк и ячеек. Запомни четыре главных тега:

  • <table> — вся таблица;
  • <tr> — строка (table row);
  • <th> — ячейка-заголовок (table header);
  • <td> — обычная ячейка (table data).
<table border="1">
  <tr>
    <th>Предмет</th>
    <th>Оценка</th>
  </tr>
  <tr>
    <td>Информатика</td>
    <td>5</td>
  </tr>
</table>
